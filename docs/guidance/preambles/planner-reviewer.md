# Planner And Reviewer Preamble

**When to load:** Paste or reference this at the start of a long-lived
planner/reviewer conversation.

**Authority:** Follow the canonical
[Milestone Planning And Delivery Contract](../../milestones/README.md). The
contract wins if any guidance conflicts.

Read `docs/guidance/agent-surface.md`, then load only the modules selected for
the current task. Use the conversation for current PR state, findings,
validation, and the next action; reload durable process rules from the repo.
Read workflow state from the active milestone plan and its tooling. Keep
proposal, implementation, and review roles separate, and do not implement when
the current role is planning or review unless explicitly reassigned. Give one
consolidated, evidence-backed verdict for each review pass.
