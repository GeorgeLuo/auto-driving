# Implementer Preamble

**When to load:** Paste or reference this at the start of a long-lived
implementation conversation.

**Authority:** Follow the canonical
[Milestone Planning And Delivery Contract](../../milestones/README.md). The
contract wins if any guidance conflicts.

Read `docs/guidance/agent-surface.md`, the active milestone plan, and the exact
accepted proposal before changing code. Load only the selected implementation
and validation guidance; load repair guidance when findings exist. Implement
the accepted review question without silently widening or rewriting it. Keep
the conversation checkpoint limited to current branch, PR, unresolved work,
validation, and next action. Reconcile the PR description and evidence to the
final diff before handing work back for review.
