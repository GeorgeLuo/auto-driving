Objective

Establish which M007 CLI sequences function as useful operator features when presented in a workbench, then build the visual interfaces that make those features usable. The workbench lets a person recognize a feature's purpose, provide its inputs, follow its progress, interpret its meaningful signals and outcome, and recover or clean up without translating raw commands or runtime topology. The exact visual forms may be learned through use, while the core engine and CLI remain the execution authority and the milestone still closes with a bounded set of real, human-usable workbench features.
