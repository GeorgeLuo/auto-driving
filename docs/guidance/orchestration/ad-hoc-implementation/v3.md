# `ad-hoc-implementation/v3`

**Status:** current experimental policy

**Use when:** bounded implementation; no accepted proposal; existing repository
authority is enough.

**Do not use when:** product discovery, new user journey, unresolved acceptance
contract, safety/authority change, external schema decision, or substantial
scope expansion. Escalate those instead of implementing them.

Canonical [contract](../../../milestones/README.md) wins. No phase-transition
authority. Apply shared [min-max](../README.md#shared-definitions).

## Invocation

```text
Follow orchestration policy ad-hoc-implementation/v3 for this change.
```

## Definitions

```yaml
topology:
  default: root_compiles_then_delegates
  live_subordinates_default: 1
  coordinator_default: false
  substantial_edits_before_manifest: false
  first_of_kind_slice_before_fanout: true   # when units are repeated/analogous
  implementation_units_execute_on: child

sync:
  mechanism: terminal_receipt
  forbidden: [model_polling, progress_prompts, stdin_peeks, sleep_wait_loops]
  clarification_max: 1
  repeated_clarification: recompile_or_redispatch
  child_requires: terminal_receipt_without_model_polling
  else: collapse_to_root

runtime:
  child: lowest_capable_available
  in_policy_economy_tier: sufficient
  tokens_on: unit_artifact
  steering_tokens_on: receipt
  inherit_planner_runtime: false
  escalate_if:
    [unresolved_uncertainty, missing_capability, lower_tier_failed]

delegation:
  default: always_after_compiled_packet
  required: {terminal_receipt_without_model_polling: true}
  not_grounds_to_skip:
    [small_or_tightly_coupled, root_already_holds_context,
     no_independent_parallelism, cheaper_reasoning_tier_alone]
  collapse_only_if: not terminal_receipt_without_model_polling
  cost_model:
    dense_packet: true
    high_tier_child_overhead_accepted: ~1.1x
    skip_that_tax: never_attempts_economy_path

validation:
  one_owner_per_check: true
  whole_delivery_owner: Z1
  rerun_if: [later_change_can_invalidate, final_head_required, contract_requires]
  reduce_output_to: [pass_fail, count, failing_identities, evidence_refs]

resume_from: [manifest, receipts, repository_head]
hidden_worker_transcripts: not_required
closure_owner: root
launch_worker_for_closure: false
```

## Flow

```text
operator request
      v
ONE root compiles manifest (dense packet)
      v
delegate each implementation unit @ lowest capable runtime
      |   first_of_kind first when a repeatable pattern is expected
      v
terminal receipt
      |
pattern/plan fit? --no--> root recompiles --> redispatch
      |
     yes
      v
root Z1 closure --> final-head validation --> delivery / PR
```

A compiled unit is delegated even when it is the only unit. Small/coupled is
not a skip. Collapse to root only when the runtime cannot return a terminal
child result without parent model turns.

## Manifest

Emit before substantial edits or worker launches. Prose planning is not policy
state unless it is in this object.

```yaml
policy: ad-hoc-implementation/v3
manifest_revision: 1
objective: <bounded operator request>
constraints: [<existing authority / behavior to preserve>]
non_goals: [<explicitly excluded work>]
authority: [<owner / contract / public path>]
units:
  - id: A1
    role: first_of_kind
    objective: <complete representative slice>
    implementation_shape: <expected transformation>
    owner: child
    runtime: lowest_capable_available
    validation:
      - {check: <focused check>, owner: A1, rerun_at_closure: false}
    escalate_if: [<assumption invalidation>]
  - id: A2
    role: pattern_following
    objective: <remaining analogous work>
    pattern_from: A1
    owner: child
    runtime: lowest_capable_available
    validation:
      - {check: <focused check>, owner: A2, rerun_at_closure: false}
  - id: Z1
    role: closure
    owner: root
    includes:
      - public / registry / consumer wiring still required
      - final diff-to-manifest check
      - required final-head validation
      - PR creation/update if requested
final_validation:
  - {check: <repository-required integrated check>, owner: Z1}
operator_escalation_if: [<decision not owned by this policy>]
```

```yaml
manifest_revision:
  increment_when: mechanics_change_and_objective_authority_intact
  record: [failed_assumption, superseded_unit]
escalate_instead_of_revise_when:
  [objective, acceptance_contract, owner, safety_boundary, operator_visible_behavior]
```

## First slice / pattern

Required when units are repeated or analogous. The slice must cross later
boundaries: implementation, wrapper, registry, public dispatch, consumer/report
behavior, focused public-path validation. Root writes the packet; the child
executes the slice.

```yaml
pattern:
  id: <pattern-id>
  source_unit: A1
  status: accepted
  applies_when: [<boundary condition>]
  procedure: [<repeatable transformation>]
  validation: [<focused check>]
  escalate_if: [<condition where pattern stops applying>]
not_accepted_if_only: [internal_module_compiles, isolated_unit_test_passes]
on_cross_boundary_anomaly: revise_manifest_before_continuing
```

## Child dispatch / receipt

Child gets the compiled unit, accepted pattern if applicable, and the
repository context for that unit. Parent does not also load that context.

```yaml
policy: ad-hoc-implementation/v3
manifest_revision: 1
unit: A2
objective: <bounded transformation>
pattern: <pattern-id or null>
runtime: <lowest capable available runtime>
constraints: [<must preserve>]
validation:
  - {check: <focused check>, owner: A2}
escalate_if:
  - pattern does not apply cleanly
  - another owner/boundary appears
  - public behavior differs from the manifest assumption
  - validation exposes an unpredicted failure class
  - scope/product judgment is required
return_schema:
  [unit, manifest_revision, head, status, plan_fit, changed_files,
   validation, anomalies, evidence_refs]
```

```yaml
unit: A2
manifest_revision: 1
head: <sha>
status: complete
plan_fit: matched
changed_files: [<path>]
validation:
  - {check: <identity>, status: pass}
anomalies: []
refs: {diff: <ref>, validation: <ref>}
```

Invalidated work order → bounded anomaly, no self-broadening. Raw logs/diffs
are refs; they enter root context only if the receipt is insufficient.

Lifecycle: `dispatch once -> terminal receipt once -> release child`.

## Local recompile

On contradiction with the manifest, raise attention only on the affected
boundary. Choose: `revise_manifest` | `corrected_dispatch` | `escalate` |
`abort`. `root_executes` only when `terminal_receipt_without_model_polling`
is false. Rebuild the whole plan only if objective/authority was wrong.

## Z1 closure

1. reconcile completed units to latest `manifest_revision`
2. finish in-scope public/registry/consumer wiring
3. run required final-head/integrated validation only
4. unresolved anomalies/authority == []
5. diff ⊆ objective/constraints/non_goals
6. create/update requested delivery artifact

## Complete / escalate

```yaml
complete_when:
  - objective implemented
  - units complete or explicitly superseded
  - required_validation pass on final head
  - diff in scope
  - no unresolved authority anomaly
  - delivery artifact exists
escalate_when:
  - product_definition
  - unowned_user_visible_choice
  - contract_safety_schema_or_ownership_change
  - material_scope_expansion
  - repeated_recompile_shows_not_bounded
  - validation_falsifies_request
```
