# `product-implementation/v1`

**Status:** experimental; awaiting a real frontier trial.

**Use when:** operator-assigned implementation of one accepted frontier proposal.

**Do not use when:** no accepted proposal; proposal/amendment still in review;
idle current; product discovery; independent review, acceptance, merge, or
closeout.

Canonical [contract](../../../milestones/README.md) wins. Pin
[shared/v2](../shared/v2.md#shared-definitions).

## Invocation

```text
Follow orchestration policy product-implementation/v1 to implement
<accepted proposal> on <milestone branch>. Deliver ready for independent review.
```

## Flow

```text
accepted proposal + recorded workflow state
      v
ONE root compiles packet
      v
ONE worker: complete slice @ lowest capable runtime
      v
shared/v2 wait
      |
terminal receipt | timeout_kind
      |
plan/contract fit? --mechanics fail--> root recompiles --> redispatch
      |
      |-- contract change --> canonical escalation
      v
    matched
      |
work remains? --yes--> next unit
      v
root Z1 closure --> ready for independent review
```

## Decision routing

| Observation | Owner / next action |
| --- | --- |
| Algorithm, layout, or internal choice left open | Worker chooses within constraints; validate public behavior; record material decision. |
| Pattern fails; accepted outcome/owner hold | Root revises affected unit, records failed assumption, redispatches. |
| Another file needed within accepted owner/behavior | Worker reports path/reason; root reconciles packet. File drift alone is not contract drift. |
| Question, non-goal, safety/authority, schema, assumption, owner, criterion, or handoff must change | Stop dependent work; canonical amendment/later-frontier route. |
| Human requests additive behavior during testing | Canonical HITL classification; no automatic adjunct authorization. |
| External capability missing | Identify owner/minimum contract; canonical capability-gap route. |
| `timeout_kind=no_final_response` | Preserve commits/checkpoints; recover receipt; not no-activity. |
| `timeout_kind=no_activity` | Terminal anomaly; do not adopt unverified edits. |
| Runtime lacks liveness wait | Direct execution or saved handoff; record actual activations; do not kill while live. |

## Z1 closure

```yaml
Z1:
  owner: root
  steps:
    - reconcile: [completed_units, paths, decisions, anomalies] -> proposal+amendments
    - finish: scoped_integration
    - verify: [integrated_checks, final_head, evidence]
    - pr:
        template: canonical_implementation
        include: [exact_validation, limitations, proposal_refs, real_repair_history]
        batch_metadata: true
    - persist: run_outcome
    - handoff: ready_for_independent_review
```

## Complete / escalate

```yaml
complete_when:
  - accepted_scope_delivered
  - required_validation pass on final head
  - evidence_obligations_met
  - unresolved_anomalies: []
  - implementation_pr_accurate
  - handoff_recorded
next: independent_implementation_review
not_authorized:
  [self_acceptance, merge, milestone_completion, frontier_advance,
   automatic_review_loop]
explicitly_composed_review:
  requires: ordinary_role_and_phase_assignment
  packet: fresh_exact_head_same_accepted_question
escalate_when:
  - accepted_question_or_contract_must_change
  - safety_schema_ownership_external_or_handoff_change
  - human_additive_request_needs_HITL_classification
  - missing_external_capability
  - receipt_not_actionable_after_one_clarification
  - operator_judgment_required
```
