# `shared/v2`

**Status:** current shared pin for new policies

**Use when:** a versioned orchestration policy explicitly pins `shared/v2`.

```yaml
pin: shared/v2
supersedes_as_current: shared/v1
v1_remains_for: runs_and_policies_that_named_it
```

Substantive changes require a new shared version. The canonical milestone
[contract](../../../milestones/README.md) wins over these defaults and policy-
specific invariants win over them within the selected policy.

## Shared definitions

```yaml
min_max:
  defined_work:
    examples: [frozen_review, approved_repair, accepted_pattern, owned_validation]
    compute: lowest_capable_available
    tokens: artifact   # source, tests, diffs, evidence
    in_policy_economy_tier: sufficient
    execute_on: child
  steering:
    actors: [root, executive]
    tokens: dense_receipt
    receipt_fields:
      [head, status, finding_ids, pass_fail, evidence_refs,
       last_activity_at, last_activity_type, timeout_kind]
    forbidden_inputs:
      [repo_reread, raw_logs, worker_transcripts, poll_wait_output]
    owns: [compile_packet, disposition, recompile, closure]

runtime:
  child_default: lowest_capable_available
  escalate_if:
    [unresolved_uncertainty, missing_capability, lower_tier_failed_with_evidence]
  not_escalate_if: [work_involves_judgment]
  inherit_planner_runtime: false

delegation:
  default: always_after_compiled_packet
  collapse_only_if: runtime_lacks_terminal_receipt_or_liveness_wait
  not_grounds_to_skip:
    [small_or_tightly_coupled, root_already_holds_context,
     no_independent_parallelism, first_wait_window_may_elapse]
  cost_model:
    dense_packet: true
    high_tier_child_overhead_accepted: ~1.1x
    # Skipping that ~10% tax also skips economy-tier attempts (~1/40th work cost).

smell:
  compiled_unit_executed_on_root: requires_explanation
  valid_explanations: [runtime_lacks_terminal_receipt_or_liveness_wait]
  invalid:
    [direct_mode_too_small, spawn_child_to_satisfy_metric,
     kill_on_first_window_while_live]

defaults:
  live_subordinates: 1
  coordinator: false
  sync: terminal_receipt
  wait: liveness_deadline
  sync_forbidden:
    [model_polling, progress_prompts, stdin_peeks, sleep_wait_loops,
     short_wait_loops, worker_file_peeks, transcript_peeks]
  sync_allowed_on_deadline: one_compact_status_probe
  clarification_max: 1
  validation: {one_owner_per_check: true}
  closure_owner: parent
  resume_from: [visible_policy_state, repository_state]
  checkpoint: [slice_complete, before_long_validation]
  timeout_must_not_discard: [commits, checkpoints]

wait:
  clocks: {task_deadline: <duration>, idle_deadline: <duration>}
  sign_of_life:
    [agent_message, checkpoint, tool_activity, filesystem_diff_or_commit,
     test_output, explicit_heartbeat]
  on_sign_of_life: reset_task_and_idle_deadlines
  on_task_deadline:
    before_shutdown: one_compact_status_probe
    to: same_child
    count: 1_per_deadline_event
  on_probe_response_or_life:
    reset: [task_deadline, idle_deadline]
    continue: bounded_extension
  terminate_when:
    {bounded_probes_or_extensions_exhausted: true, no_sign_of_life: true}
  do_not_terminate_when: {live: true, only_first_task_window_exceeded: true}
  timeout_kind:
    none: terminal_receipt
    no_final_response: live_or_checkpointed_without_receipt
    no_activity: silent_after_bounded_probes
  expose: [timestamps, last_activity_type, current_status, timeout_kind]
  status_probe:
    is: wait_status_activation
    is_not: [model_polling, progress_prompt, poll_wait_turn]
  if_runtime_lacks_liveness_wait:
    choose: [direct_execution_at_capable_runtime, explicit_saved_handoff]
    not: [kill_while_live]
    record: runtime_limitation_and_actual_activations

wait_metrics:
  wait_status_activations: <count>
  status_probes: <count>
  deadline_resets: <count>
  timeout_kind: none | no_final_response | no_activity
  poll_wait_turns: <count>                 # target: 0
  first_window_kills_while_live: 0
```

## Wait

```text
child running
      |
      |-- sign_of_life --> reset task_and_idle_deadlines --> continue
      |-- terminal receipt --> timeout_kind=none
      |-- live + first_window_exceeded --> do_not_kill --> continue
      |
task_deadline
      v
ONE compact status_probe --> same child
      |
      |-- response or life --> reset clocks; bounded_extend --> continue
      |-- no life, probes remain --> wait idle_deadline --> continue
      |-- probes exhausted + idle --> timeout_kind=no_activity; terminate
      |
no receipt after stop --> timeout_kind=no_final_response; preserve checkpoints
```
